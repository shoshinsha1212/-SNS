# 04 プライバシーと不正対策

立場（属性）を集めて見せることがこのサービスの中心なので、**属性データの扱い**と**立場を偽る不正**が最大のリスクになります。

## 1. 属性データの扱い

### 1.1 法律上の位置づけ（日本）

- 投票の中身（倫理観や価値観）と属性を組み合わせると、個人情報保護法の**要配慮個人情報**（「信条」など）にあたるおそれがある。要配慮個人情報は、取得の際に**本人の同意**が必要。
- 対応：
  - 登録時に、属性と投票を「どの目的で・どう集計し・誰に何を見せるか」を明示して同意を取る。
  - 立場の軸に、思想・信条・政党支持・宗教・病歴などを使わない（[03 の P3](./03_AIパイプライン.md#p3-立場の軸の提案) で禁止）。
  - 属性はすべて任意入力とし、未入力でも投票はできるようにする（その票は立場別の集計には入らない）。

> [!IMPORTANT]
> 正式な公開の前に、個人情報保護法に詳しい専門家の確認を受けてください。この章は設計の方向性であり、法的な助言ではありません。

### 1.2 公開するもの・しないもの

| データ | 本人 | 他の参加者 | 外部（成果物・API） |
|--------|------|------------|---------------------|
| 個々の票 | 見える | **見えない** | **出さない** |
| 自分の属性・立場 | 見える | 体験談の書き手として立場だけ表示（本人が選択） | 出さない |
| 意見マップ上の位置 | 自分の点だけ強調 | 他人の点は匿名の点として表示 | 出さない |
| 立場ごとの集計 | 見える | 見える（最小人数ルールつき） | 見える（最小人数ルールつき） |
| 体験談 | 見える | 匿名化したものが見える | 引用は要約のみ |

### 1.3 最小人数ルール（再識別の防止）

- 立場ごとの集計は、**その立場の人数が10人以上**の場合だけ表示する。10人未満の立場は「その他」にまとめる。
- 立場の組み合わせ（例：「使う側 × 20代 × 地方」）での集計は、組み合わせごとに10人以上ある場合だけ表示する。表示できる組み合わせは、軸2本までにする。
- 参加者数が少ないトピック（立場の数×10人未満）では、立場別の表示を出さず「人数がそろうと立場ごとの違いが表示されます」とする。
- 将来的に外部へデータを公開する場合は、集計値に小さなノイズを加える差分プライバシーの導入を検討する。

## 2. 不正対策

### 2.1 想定する不正

| 不正 | 影響 |
|------|------|
| **立場の偽装**：ある立場になりすまして投票する | 「◯◯の立場の人はこう考えている」という結果が歪む。このサービスで最も深刻 |
| 組織票：多数のアカウントで同じパターンの投票をする | 共通原則・分岐点の判定が歪む |
| 体験談の捏造 | 追体験の信頼性が下がる |

### 2.2 対策

**信頼レベル**（`USER.trust_level`）を設け、集計に重みをつけます。

| レベル | 条件 | 集計での重み |
|--------|------|--------------|
| 0 | 登録直後 | 0（投票はできるが集計に入らない。最初の24時間または10票まで） |
| 1 | メール認証＋一定期間の利用 | 1.0 |
| 2 | 電話番号認証など、1人1アカウントを担保する認証 | 1.0 |
| 3 | 立場の証明（例：教員であれば学校のメールアドレス、所属団体の確認） | 1.0（立場に「確認済み」の印） |

- 成果物には、全体の集計に加えて**「立場の確認済みの人だけの集計」**を並べて載せられるようにし、両者が大きく違えば注意書きを出す。
- 投票パターンの異常検知：短時間に、新しいアカウントの群れがほぼ同じ投票をした場合、その票を保留して運営が確認する。
- 立場の変更は30日に1回までとし、変更履歴を残す（[01 の 2.2](./01_データモデル.md#22-立場は投票時点の写しスナップショットを残す)）。

> [!NOTE]
> 立場の証明を厳しくするほど参加のハードルが上がり、参加者が減ります。最初はレベル1を標準とし、テーマに応じてレベル3を任意で用意するのが現実的です。

## 3. 表示上の倫理

立場によって意見が決まることを見せる仕組みは、使い方を誤ると**「どうせ◯◯の立場の人はこう言う」という決めつけ（ステレオタイプ）を強める**おそれがあります。次のルールで抑えます。

1. **立場の違いは、必ず体験談とセットで見せる**：数字だけで「◯◯の人は反対」と出さず、なぜそう考えるのかの体験談を並べる。
2. **同じ立場の中の少数派も必ず見せる**：「規制する側の21%は賛成」のように、立場の中にも違いがあることを示す。境界人の体験談（[02 の 2.7](./02_アルゴリズム.md#27-境界人の検出-)）がその役割を持つ。
3. **動機を決めつけない**：「立場依存度が高い＝利害で発言している」とは限らない（[02 の 2.4.4](./02_アルゴリズム.md#244-解釈の注意画面の表現に関わる)）。画面の文言は「立場によって見え方が大きく違う論点」とする。
4. **個人の診断は本人だけに見せる**：立場らしさスコアを他人に見せる機能は作らない。本人がシェアする場合も、シェア用の画像には個々の票を含めない。
5. **参加者の偏りを常に示す**：自由参加のため、立場ごとの人数や参加者の偏りを成果物と集計画面に必ず表示する。
