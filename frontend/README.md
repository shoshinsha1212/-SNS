# 成果型SNS フロントエンド（React + TypeScript + Vite）

## 起動方法

1. 先にバックエンド（`http://localhost:8000`）を起動します。
2. 別ターミナルで以下を実行します：

```powershell
cd frontend
npm run dev
```

ブラウザで `http://localhost:5173` を開くと利用できます（`/api` へのリクエストは自動的に `http://localhost:8000` に転送されます）。

## ビルド確認

```powershell
cd frontend
npm run build
```
